# 가족여행 가이드 (모바일)

폰에서 보기 좋게 만든 가족여행 가이드. **로그인 없이** 열립니다.

- 🇦🇺 [시드니 8박 9일](./sydney/) — 2026.11.14~23
- 🌺 [오키나와 3박 4일](./okinawa/) — 2026.9.17~20

## 특징
- 탭 기반 단일 컬럼 (폰 우선)
- 장소명 탭 → 구글맵 앱 열림
- 비상 연락처 탭 → 바로 통화 (`tel:`)
- 준비물 체크리스트 (브라우저에 저장)
- 다크모드 대응
- 사진은 base64 임베드 (외부 요청 없음)

## 주의
- 이 저장소는 공개이므로 **신원 정보(예약번호·실명)를 넣지 않습니다.**
- 원본(전체 정보 포함)은 로컬 PDF로만 보관합니다.

로컬 소스를 수정한 뒤 `index.html`을 이 저장소에 복사 → commit/push → 2~3분 뒤 Pages 반영. URL 유지됩니다.
