- 🌺 [오키나와 3박 4일](./okinawa/) — 2026.9.17~20

- 🔤 [한글 놀이](./hangul/) — 아이용 한글 게임: 글자 만들기 · 듣고 찾기 · 낱말 완성 · 따라 쓰기 (오프라인 동작, 고친 뒤엔 `hangul/sw.js`의 CACHE 숫자를 올릴 것)
- 🎮 [몽팸게임방](./games/) — 꼬마 조종사(비행기) · 아이스 대시 · 에이펙스 스프린트. 시드니 가이드의 🎮 게임 탭에서도 열림

## 오프라인(비행기 안)
- 시드니 가이드를 인터넷이 될 때 **한 번 열면** 가이드·짐 체크·게임방·시계·한글이 모두 기기에 저장되어 인터넷 없이 열립니다.
- 날씨 탭과 짐 체크 같이 보기는 인터넷이 있어야 새로 받아 옵니다.
- 고친 뒤 저장본을 확실히 바꾸려면 `sydney/sw.js`, `games/sw.js`의 CACHE 숫자를 올립니다(인터넷이 되면 어차피 새 버전을 먼저 받음).
- `sydney/index.html`을 통째로 다시 복사할 때 맨 끝의 serviceWorker 등록 `<script>`를 살릴 것.
- 게임 원본: `~/Desktop/파프짐 팀 세팅/게임모음_20261111/` (games/*.html에 noindex 메타와 맨 끝 serviceWorker 등록을 붙여 복사)

## 특징
- 탭 기반 단일 컬럼 (폰 우선)
- 장소명 탭 → 구글맵 앱 열림
- 비상 연락처 탭 → 바로 통화 (`tel:`)
- 준비물 체크리스트 (브라우저에 저장)
- 다크모드 대응
- 사진은 base64 임베드 (외부 요청 없음)

## 주의
- 이 저장소는 공개이므로 **신원 정보(예약번호·실명)를 넣지 않습니다.**
- 원본(전체 정보 포함)은 로컬 PDF로만 보관합니다.
